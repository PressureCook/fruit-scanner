# **App Name**: FreshScan

## Core Features:

- Live Camera Feed: Displays a real-time camera feed to easily capture images of fruit.
- Image Capture & Selection: Allows users to capture new photos or select existing images from their device's gallery for analysis.
- AI Fruit Classifier: Utilizes a machine learning model to classify whether the photographed fruit is rotten or healthy.
- Classification Result Display: Clearly presents the AI's classification result (rotten/healthy) to the user with a confidence score.
- Retake/Re-select Option: Provides options to retake a photo or re-select an image if the user is not satisfied with the previous capture.

## Style Guidelines:

- Color Anchor: Freshness and vitality. Light scheme for a clean and inviting appearance. Primary color: A lively, natural green (#33A133), representing health and organic produce. Background color: A very soft, desaturated green (#F6FCF6) providing a calm backdrop. Accent color: A bright yellow-green (#94EB00), used for calls to action and highlights, evoking zest and energy.
- Body and headline font: 'Inter' (sans-serif) for its modern, highly readable, and objective appearance, suitable for clear presentation of results.
- Use clear, universally recognizable icons for camera, gallery, and health status indicators (e.g., a green checkmark for healthy, a red 'X' or simple decaying fruit icon for rotten).
- Clean, focused layout with the camera view or image preview taking center stage. Classification results should be prominently displayed directly below the image with clear, legible text.
- Subtle, quick transitions when moving between camera view and result display. A brief loading animation during AI classification to indicate processing.
